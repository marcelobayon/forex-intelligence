# Forex Intelligence

Personal, **paper-only** EUR/USD market-monitoring, strategy-analysis, and backtesting platform. An **honest measurement system** for Marcelo's trading strategy — not a bot built to look profitable, and not a real-money trader.

> ⚠️ **Status: DRAFT / Phase 0.** No application code yet. The strategy rules are **candidate hypotheses under investigation — not approved production rules.** No real-money execution exists or is planned in this phase.

## Three questions this project keeps separate

1. **Reproduction** — can it reproduce what was observed? (journal reconciliation)
2. **Objective identification** — can it identify the setup from explicit rules? (engine validation)
3. **Measurable edge** — does it pay after costs? (historical, then forward)

Passing one does not prove the next.
